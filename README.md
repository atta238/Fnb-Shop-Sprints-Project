# 🍔 Online Food & Beverage Shop  
A responsive e-commerce website built using **HTML5** and **CSS3**, designed as a graduation project for the Web Fundamentals SprintUP program.

---

## 📌 Project Overview
This project is a simple, static online shop for Food & Beverage products. It includes a homepage, product listing page, about page, and a contact form. The site is fully responsive and follows modern UI/UX best practices.

---

## 🎯 Objectives
- Implement a clean HTML5 structure using semantic tags.
- Style and layout the website using modern CSS3 techniques (Flexbox / Grid).
- Design a consistent navigation bar and footer across all pages.
- Create a functional and validated contact form.
- Ensure full responsiveness for mobile, tablet, and desktop users.

---

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
